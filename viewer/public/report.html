🎬 Sector 1: Video Preprocessing & Frame Curation
reconstruction/preprocessing/extract_curate_v3.py
Primary Tool

Input Asset
IMG_3363.MOV (1080p, 30 FPS Walkthrough)
Output Asset
data/processed/custom-video-v3/images/ (370 frames)
Measured Duration
1m 45s (~1.5 – 2 mins)
Algorithmic Mechanism:
  • Temporal Resampling: Decodes stream at 5.0 FPS into 1280x720 frames using Lanczos scaling.
  • Dynamic Artifact Removal: Purges frames 222–263 to remove transient human motion and prevent phantom floaters.
  • Laplacian Variance Scoring: Evaluates edge variance Var(∇²I) and discards the blurriest 25% of panning frames to yield 370 curated frames.
def curate():
    all_raw = sorted(glob.glob(os.path.join(raw_dir, "frame_*.jpg")))
    person_frames = {f"frame_{i:05d}.jpg" for i in range(222, 264)}
    non_person_files = [f for f in all_raw if os.path.basename(f) not in person_frames]

    scored_frames = []
    for fpath in non_person_files:
        img = cv2.imread(fpath)
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        lap_var = float(cv2.Laplacian(gray, cv2.CV_64F).var())
        scored_frames.append((fpath, lap_var))

    scored_frames.sort(key=lambda x: x[1])
    k_drop = int(len(scored_frames) * 0.25)
    kept_frames = scored_frames[k_drop:]

🧹 Sector 4: Geometric & Color Filtering Pass (SuperClean)
reconstruction/pipeline/clean_splat.py
Primary Script

Filtering Passes

Final Splat Count
102,242 splats (24.3 MB)
Measured Duration
1m 10s (~1 – 1.5 mins)
Algorithmic Mechanism:
  • Statistical Outlier Removal (SOR): Queries k=16 nearest neighbors via KD-Tree; prunes splats exceeding mean + 1.5σ distance.
  • Needle Aspect Ratio Bounding: Limits eccentricity (s_max ≤ 4.0 * s_mid) to turn spiky needles into flat surface discs.
  • SH Defect Clamping: Simulates multi-view directions and zeroes degree-2 SH rest coefficients on splats producing dark/negative glancing radiance.

export class POIManager {
  update() {
    this.labels.forEach((item) => {
      const pos3D = item.worldPos.clone().project(this.camera);
      if (pos3D.z < 1.0) {
        const x = (pos3D.x * 0.5 + 0.5) * window.innerWidth;
        const y = (-pos3D.y * 0.5 + 0.5) * window.innerHeight;
        item.element.style.transform = `translate(-50%, -50%) translate3d(${x}px,${y}px,0)`;
        item.element.style.display = 'block';
      } else {
        item.element.style.display = 'none';
      }
    });
  }
}
