Sector 1: Video Preprocessing & Frame Curation
reconstruction/preprocessing/extract_curate_v4.py
Primary Tools
FFmpeg 9.0.2, OpenCV (Laplacian), NumPy
Input Source
IMG_3780.MOV (4K 120FPS HDR, iPhone 17 Pro Max)
Output Target
data/processed/custom-video-v4/images/ (376 frames)
Standard Resolution
720 × 1280 px (9:16 portrait upright)
Technical Responsibilities:
  • Resolution & Rotation Normalization: Honors the iPhone sensor rotation (-90°) while downscaling native 4K to 720×1280 to prevent CPU/GPU memory thrashing.
  • Laplacian Variance Filtering: Samples candidates at 6 FPS into temporal buckets of 2.5 FPS, scoring spatial gradients via Var(∇²I) to automatically drop motion-blurred frames.
def run_pipeline(video_path, base_out_dir, target_fps=2.5, sample_fps=6.0, max_width=720):
    # Standardize scaling while maintaining native upright aspect ratio
    vf_filters = [f"fps={sample_fps}"]
    if max_width: vf_filters.append(f"scale='min(iw,{max_width})':-2")
    
    # Step 1: Candidate frame extraction
    cmd = [ffmpeg_bin, "-y", "-i", video_path, "-vf", ",".join(vf_filters), "-qscale:v", "2", raw_pattern]
    subprocess.check_call(cmd)

    # Step 2: Temporal window curation via Laplacian variance
    for bucket in time_windows:
        best_cand = max(bucket, key=lambda p: cv2.Laplacian(cv2.cvtColor(cv2.imread(p), cv2.COLOR_BGR2GRAY), cv2.CV_64F).var())
        shutil.copy2(best_cand, target_img_dir)
Sector 2: Structure-from-Motion (SfM) Tracking & Intrinsics
reconstruction/pipeline/run_colmap_v4.py
Primary Tool
COLMAP 4.2.0 (14 CPU Worker Threads)
Camera Model
OPENCV (fx=1059.4px, fy=1050.3px, ~62° FOV)
Registered Views
205 Cameras in Dominant Cluster
3D Anchor Points
49,686 Triangulated Sparse Landmarks
Technical Responsibilities:
  • Multi-threaded SIFT: Extracts ~6,500 scale-invariant features per frame across 14 CPU threads.
  • Sequential Overlap Matching: Applies quadratic temporal lookahead (overlap=20) to track camera movement along the room walkthrough.
  • Non-Linear Bundle Adjustment: Solves radial/tangential lens distortion (k1, k2, p1, p2) and establishes metric 3D camera trajectory.

# 3. Incremental mapping

Technical Responsibilities:
  • Needle Clamping: Eliminates razor-thin elongated Gaussians (up to 170:1) created by ray errors, maintaining clean planar shapes.
  • SOR Floater Filtering: Removes isolated stray noise clusters floating in room air.
  • Spherical Harmonics Clamping: Evaluates radiance from 35 camera viewpoints, zeroing overfitted Degree-2 rest coefficients for splats that drop below zero RGB to prevent black burn artifacts.

Technical Responsibilities:
  • Geometric Label Anchoring: Maps 3D world coordinates of furniture to 2D screen DOM pills without drift during camera rotation.
  • Interactive Camera Flight: Clicking any POI triggers a smooth cinematic flight landing 0.8m directly in front of the object.
export class POIManager {
  update() {
    this.labels.forEach((item) => {
      const pos3D = item.worldPos.clone().project(this.camera);
      if (pos3D.z < 1.0) {
        const x = (pos3D.x * 0.5 + 0.5) * window.innerWidth;
        const y = (-pos3D.y * 0.5 + 0.5) * window.innerHeight;
        item.element.style.transform = `translate(-50%, -50%) translate3d(${x}px,${y}px,0)`;
      }
    });
  }
}
